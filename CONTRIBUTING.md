# Contributing to AtlasLatino

Want to add a talk, a person, or an event? There are two ways to do it.

## Option 1: Open an issue

If you don't want to edit files yourself, open an issue with the details of the talk, person, or event you want added. Include as much as you can: name, links, a short bio or description, and the event it belongs to if any. Someone will turn it into a PR.

## Option 2: Open a pull request

If you're comfortable editing files, fork this repo, add a Markdown file under `src/content/`, and open a PR. Look at the existing files in that folder for the format to follow, and check `scripts/schemas.js` for the required fields. Run `pnpm run validate` before opening the PR to make sure your file passes.

## Option 3: Fill the request for talks for a conference

We will attempt to open a request for talks at a given conference, so we can do batch process. You can comment on the already existing issue with the new talk to add.

## Questions

Open an issue if you're not sure about something. That's the easiest
way to reach us.
